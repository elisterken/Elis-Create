# Welcome to Eli's Create!

**Eli's Create** is a simple, minimal, and not too OP Minecraft modpack based around the [Create](https://modrinth.com/mod/create) mod. The pack includes Create with some of it's addons,
as well as some QOL and performance mods. I created this pack for myself after finding many Create modpacks too bloated or OP, and have decided to share it with the world :)

### Feedback

Any ideas, suggestions, or contributions are very welcome! Feel free to send me an [Email](mailto:sterk.eli@outlook.com) or submit a PR in the GitHub repository.

### Technical

This pack is created and maintained with [Packwiz](https://packwiz.infra.link/), a CLI tool for developing Minecraft modpacks. Please install and get familiar with Packwiz before contributing to the
pack. If you make any changes to the mods or configs, please document them in the README. **Client and Server Compatibility:** On paper, this pack should work fine client and server-side. However, I have not tested it on a server so I've marked it as client only for now.
Feel free to try it on your server, and let me know if you encounter any issues.

<details>
  <summary>Custom Configs</summary>

  - WTHIT: Enabled fluids by default
  - Burnt: Lightning starts fires, and ember spread and smoke fog are enabled
  - Create Connected: Copycats are disabled (due to Copycats+) and the kinetic battery is removed
  - Create: Mobs don't aggravate on deployers, spawners and budding amethyst are movable by minecart contraptions, and the pump range is 128
  - Gravestone Mod: Obituary is disabled
</details>
